# 🌌 Northern Lights - Dynamic Image Gallery

A simple and responsive **Dynamic Image Gallery** built using **React.js**.  
This project displays beautiful Northern Lights destinations from different locations around the world.

## 🚀 Features

- 🌌 Northern Lights destination gallery
- ⚛️ Built with React.js
- 🔄 Dynamic rendering using JavaScript `map()`
- 🧩 Reusable React components
- 🖼️ Local `.avif` images
- 📍 Displays destination and location
- 📱 Responsive design
- 🎨 Simple and clean UI

## 🗺️ Destinations

- Orkney Islands – Scotland
- Tromsø – Norway
- Abisko – Sweden
- Kiruna – Sweden
- Reykjavík – Iceland
- Fairbanks – USA
- Yellowknife – Canada
- Whitehorse – Yukon, Canada
- Ilulissat – Greenland
- Svalbard – Norway
- Rovaniemi – Finland
- Aurora Borealis – Iceland
